# 进度条生成器 | Progress Bar Generator

为视频创作者打造的进度条素材生成工具。轻松创建精美的视频进度条动画，支持多种样式和导出格式。

![Progress Bar Generator](https://img.shields.io/badge/React-18-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![Vite](https://img.shields.io/badge/Vite-7-purple)

## 功能特性

- **多种进度条样式**
  - 直线进度条 - 经典简约风格
  - 渐变进度条 - 炫彩渐变效果
  - 圆形进度条 - 环形进度显示
  - 波浪进度条 - 动态波浪效果
  - 点阵进度条 - 独特点状显示

- **丰富的自定义选项**
  - 自定义尺寸 (宽度/高度)
  - 自定义颜色 (背景色/进度色/渐变色)
  - 圆角调节
  - 动画时长 (1-60秒)
  - 帧率调节 (10-60fps)
  - 多种缓动效果 (线性/渐入/渐出/渐入渐出)
  - 发光效果开关
  - 百分比显示

- **实时预览**
  - 播放/暂停控制
  - 进度拖拽
  - 即时效果预览

- **多种导出格式**
  - PNG 序列 (适合专业视频编辑软件)
  - GIF 动画 (适合快速预览分享)
  - 单帧导出

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 技术栈

- **React 18** - 用户界面
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **Tailwind CSS** - 样式框架
- **Canvas API** - 进度条渲染
- **gif.js** - GIF 生成
- **JSZip** - PNG 序列打包
- **Lucide React** - 图标库

## 使用指南

1. **选择样式** - 在左侧面板选择喜欢的进度条样式
2. **调整参数** - 设置尺寸、颜色、时长等参数
3. **预览效果** - 点击播放按钮预览动画效果
4. **导出素材** - 选择合适的格式导出

### 导出建议

- **视频编辑** - 推荐导出 PNG 序列，在 PR/AE/达芬奇等软件中导入
- **快速分享** - 可以导出 GIF 格式，方便预览和分享
- **静态使用** - 可以导出单帧作为图片素材

## 快速预设

底部工具栏提供了 5 种快速预设：

- **极简** - 简约直线进度条
- **霓虹** - 红橙渐变发光效果
- **圆形** - 带百分比的环形进度条
- **波浪** - 蓝色动态波浪效果
- **点阵** - 紫色点状进度显示
